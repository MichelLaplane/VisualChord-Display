Doigtés

Guitare — chiffres 1 à 4 : 1=index, 2=majeur, 3=annulaire, 4=auriculaire. ✕ = corde étouffée, ○ = corde à vide. Piano — les touches dorées indiquent la main gauche (note de basse), les touches vertes la main droite (accord complet). Répartition pédagogique standard, libre à vous de l'adapter. Lorsqu'un accord rare n'existe pas dans la base de doigtés de guitare, un doigté est généré automatiquement à partir des notes de l'accord (mention « généré »).

Base de doigtés de guitare : chords-db (open source). Positions main gauche/droite calculées par théorie musicale.
